# LOAF BREAKER VST (privé)

LOAF BREAKER, le firmware de FLEXOR pour le M-VAVE FM-1, en plugin VST3 et en version autonome pour Windows.
Le son est celui de la machine : le plugin fait tourner le firmware lui-même (`firmware/`, le dépôt loaf-breaker en
sous-module), compilé pour PC.

- **Télécharger** : onglet *Releases* de ce dépôt (privé : seuls ses collaborateurs le voient), le dernier
  `LOAF-BREAKER-VST-N-Windows.zip`. L'installation est dans le fichier LISEZ-MOI.txt du zip.
- **Étape 1 (maintenant)** : le firmware complet dans Ableton (synchro tempo et transport, notes MIDI, sauvegarde
  dans le projet), avec l'écran et le panneau du FM-1 à la souris et au clavier.
- **Étape 2** : l'interface PC (séquenceur grand format, kick, breaks par glisser-déposer, song), sorties séparées,
  automation, glisser-déposer vers Ableton.
