LOAF BREAKER VST (Windows)

INSTALLER LE VST3 (Ableton, FL Studio...)
1. Copie le dossier "VST3\LOAF BREAKER.vst3" (tout le dossier) dans :
   C:\Program Files\Common Files\VST3\
2. Dans Ableton : Options > Preferences > Plug-ins, "Use VST3 Plug-in System Folders" sur On, puis "Rescan".
3. LOAF BREAKER apparait dans Plug-ins > VST3 > FLEXOR. Glisse-le sur une piste MIDI.

LA VERSION AUTONOME (sans Ableton)
Ouvre "Standalone\LOAF BREAKER.exe" (garde lbcore.dll et breaks.bank a cote). Windows peut afficher un avertissement
("Windows a protege votre ordinateur") : Informations complementaires > Executer quand meme. Le programme
n'est pas signe, c'est normal pour une version de test.

CE QUE LA VERSION PC A EN PLUS DU FM-1
- Les 98 breaks de la bibliotheque (le FM-1 en a 8), en qualite CD : 44,1 kHz, 16 bits, sans compression
  (le FM-1 : 22 kHz compresses). ALGORITHM les parcourt du plus lent au plus rapide.
- Les touches blanches et le split gardes pour chacun des 98 breaks.
- Le delai DUB jusqu'a 2 secondes (toutes les valeurs a tous les tempos) ; une sortie 24 bits.

LA GESTION : VST, BIBLIOTHEQUE DE KICKS, FM-1 (MENU > GESTION)
- Trois colonnes : les 20 kicks, 64 patterns et 8 tracks de la VST ; ta bibliotheque de kicks sur le PC ; ceux du
  FM-1 (LIRE LE FM-1 en USB, FM-1 a l'arret, ou OUVRIR UNE SAUVEGARDE .BAK).
- ">" ecoute un kick (de la VST, de la bibliotheque ou du FM-1) avant de le remplacer. Un clic coche.
- VST + BIBLIO >> FM-1 : ce qui est coche (et les kicks coches de la bibliotheque) va dans le FM-1 ; le reste de la
  machine ne bouge pas (ses breaks, ses reglages, ses autres kicks et patterns). Puis ECRIRE SUR LE FM-1 (il demande
  de confirmer : SEL oui) ou ENREGISTRER LE .BAK.
- FM-1 + BIBLIO >> VST : l'inverse.
- KICKS COCHES >> BIBLIOTHEQUE : chaque kick devient un fichier .lbkick dans Documents\LOAF BREAKER\Kicks, autant que
  tu veux. Double-clic : renommer. Clic droit : ranger dans un dossier, supprimer. NOUVEAU DOSSIER pour trier.
- OU ILS ARRIVENT : aux memes numeros, ou a partir d'un numero choisi (K, P, T).

LE LIEN AVEC LE FM-1 (bouton FM-1, en haut)
- "Envoyer tout au FM-1" : tes kicks, patterns, song et reglages du VST vont sur la machine. Le FM-1 doit etre
  branche en USB, arrete (pas en lecture), avec LOAF BREAKER a jour (la version avec la sauvegarde USB). Il verifie
  tout puis demande sur son ecran : SEL = oui, HOME = non. Il redemarre avec.
- "Recuperer tout du FM-1" : l'inverse, ce qui est sur la machine arrive dans le VST.
- Les breaks sont traduits par leur nom. Un break du VST que le FM-1 n'a pas (le FM-1 en a 8) est remplace par
  celui du FM-1 au tempo le plus proche ; le message dit lesquels.
- Si Ableton utilise deja le FM-1 comme clavier MIDI, Windows ne laisse pas le VST l'ouvrir : desactive le FM-1
  dans Preferences > Link/Tempo/MIDI le temps du transfert, ou passe par la version autonome.
- "Exporter / Importer une sauvegarde (.bak)" : la meme chose en fichier ; la page Backup du site LOAF BREAKER
  les envoie aussi au FM-1 depuis Chrome.

L'INTERFACE
- En haut : les categories (LIVE, SOUNDS, PATTERN, SONG, MIX, EFFECTS, ARP, SYSTEM), puis les onglets de la
  categorie, puis la partie (< >). Les 4 knobs disent ce qu'ils reglent sur la page ouverte.
- La waveform du break est toujours visible : clique une slice pour la jouer.
- SHIFT (maintenu) : les knobs deviennent ceux de SEL.
- MENU : le skin (LOAF LORD par defaut), le clavier (chaque touche reglable), l'ecran du FM-1 (a afficher ou non).

DANS ABLETON
- LOAF BREAKER suit le tempo d'Ableton et demarre a la mesure suivante quand tu lances la lecture
  (case "Host sync" en haut ; decoche-la pour utiliser son propre PLAY).
- Les notes MIDI : 48 a 63 (C3 a D#4) jouent les slices, 36 le kick, 38 la snare, 39 le clap, 42 le hat.
- La sauvegarde du projet Ableton garde tout (kicks, patterns, splits, chaos...).
- Clavier de l'ordinateur : ESPACE = PLAY ; les lettres jouent les touches (affichees dessus).
