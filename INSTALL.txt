LOAF BREAKER VST (Windows)

INSTALLER LE VST3 (Ableton, FL Studio...)
1. Copie le dossier "VST3\LOAF BREAKER.vst3" (tout le dossier) dans :
   C:\Program Files\Common Files\VST3\
2. Dans Ableton : Options > Preferences > Plug-ins, "Use VST3 Plug-in System Folders" sur On, puis "Rescan".
3. LOAF BREAKER apparait dans Plug-ins > VST3 > FLEXOR. Glisse-le sur une piste MIDI.

LA VERSION AUTONOME (sans Ableton)
Ouvre "Standalone\LOAF BREAKER.exe" (garde lbcore.dll et breaks.bank a cote). Windows peut afficher un avertissement
("Windows a protege votre ordinateur") : Informations complementaires > Executer quand meme. Le programme
n'est pas signe, c'est normal pour une version de test.

CE QUE LA VERSION PC A EN PLUS DU FM-1
- Les 98 breaks de la bibliotheque (le FM-1 en a 8), en qualite CD : 44,1 kHz, 16 bits, sans compression
  (le FM-1 : 22 kHz compresses). ALGORITHM les parcourt du plus lent au plus rapide.
- Les touches blanches et le split gardes pour chacun des 98 breaks.
- Le delai DUB jusqu'a 2 secondes (toutes les valeurs a tous les tempos) ; une sortie 24 bits.

LE CLAVIER (tout se change dans MENU > Clavier, ou CTRL+K)
- F1 a F8 : LIVE, SOUNDS, PATTERN, SONG, MIX, EFFECTS, ARP, SYSTEM. TAB / SHIFT+TAB : l'onglet suivant, precedent.
- ESPACE : PLAY. CTRL+S : sauver. CTRL+Z : annuler (pattern). CTRL+C / CTRL+V : copier, coller le pattern.
- CTRL+B : la liste des breaks. C / V : break precedent, suivant (de la playlist). CTRL+P : la playlist.
- CTRL+G : la gestion. F9 : l'apercu du FM-1 (MENU › Apercu du FM-1 : dans la fenetre ou dans une fenetre separee). N / M : tempo -1 / +1.
- Dans le sequenceur (PATTERN) : fleches pour se deplacer (SHIFT : un temps, CTRL : une mesure, DEBUT / FIN),
  ENTREE pose ou enleve le pas, SUPPR l'enleve, ALT+HAUT/BAS les HITS (le break : sa slice), SHIFT+HAUT/BAS la note du
  kick (le break : son pitch ; les autres : la chance), CTRL+HAUT/BAS la chance (le break : ses repetitions),
  ALT+GAUCHE/DROITE le nudge (le break : a l'envers), [ et ] decalent toute la ligne d'un pas.
- Dans les menus : HAUT / BAS choisissent un reglage (un cadre le montre), GAUCHE / DROITE changent sa valeur
  (SHIFT : un grand pas), ENTREE ouvre sa liste.

LE MORCEAU (SONG > TRACKS)
- Les 8 tracks sur une ligne de temps : chaque element est un bloc aussi long qu'il joue. Glisser un bloc : le
  deplacer. Molette : ses boucles. Double-clic : son pattern. + : ajouter un pattern, un DROP ou un trou. > : jouer la
  track. LOOP / STOP / HOLD : ce qu'elle fait a la fin. Dessous : le pattern, les boucles, le break, le kick de
  l'element choisi, le deplacer, le dupliquer, le supprimer.

LES BREAKS
- Clic sur le nom du break (en haut) : tous les breaks, par categorie comme sur le site (FLEXOR, CYBERWORM AMENS,
  HUGE AMEN PACK, CLASSICS, et MES BREAKS) ; la playlist ; ajouter le break a la playlist.
- < PLAYLIST > sous le nom : le break precedent, suivant de ta playlist (dans l'ordre que tu veux ; vide : tous les
  breaks). Clic sur PLAYLIST : la ranger (glisser une ligne), en ajouter, en retirer. Elle est gardee avec le projet.
- Les curseurs longs (filtres...) ont une zone OFF plus large, ombree ; double-clic : retour a OFF.

LA GESTION : VST, BIBLIOTHEQUE DE KICKS, FM-1 (MENU > GESTION)
- Trois colonnes : les 20 kicks, 64 patterns et 8 tracks de la VST ; ta bibliotheque de kicks sur le PC ; ceux du
  FM-1 (LIRE LE FM-1 en USB, FM-1 a l'arret, ou OUVRIR UNE SAUVEGARDE .BAK).
- ">" ecoute un kick (de la VST, de la bibliotheque ou du FM-1) avant de le remplacer. Un clic coche.
- VST + BIBLIO >> FM-1 : ce qui est coche (et les kicks coches de la bibliotheque) va dans le FM-1 ; le reste de la
  machine ne bouge pas (ses breaks, ses reglages, ses autres kicks et patterns). Puis ECRIRE SUR LE FM-1 (il demande
  de confirmer : SEL oui) ou ENREGISTRER LE .BAK.
- FM-1 + BIBLIO >> VST : l'inverse.
- KICKS COCHES >> BIBLIOTHEQUE : chaque kick devient un fichier .lbkick dans Documents\LOAF BREAKER\Kicks, autant que
  tu veux. Double-clic : renommer. Clic droit : ranger dans un dossier, supprimer. NOUVEAU DOSSIER pour trier.
- OU ILS ARRIVENT : aux memes numeros, ou a partir d'un numero choisi (K, P, T).

LE LIEN AVEC LE FM-1 (bouton FM-1, en haut)
- "Envoyer tout au FM-1" : tes kicks, patterns, song et reglages du VST vont sur la machine. Le FM-1 doit etre
  branche en USB, arrete (pas en lecture), avec LOAF BREAKER a jour (la version avec la sauvegarde USB). Il verifie
  tout puis demande sur son ecran : SEL = oui, HOME = non. Il redemarre avec.
- "Recuperer tout du FM-1" : l'inverse, ce qui est sur la machine arrive dans le VST.
- Les breaks sont traduits par leur nom. Un break du VST que le FM-1 n'a pas (le FM-1 en a 8) est remplace par
  celui du FM-1 au tempo le plus proche ; le message dit lesquels.
- Si Ableton utilise deja le FM-1 comme clavier MIDI, Windows ne laisse pas le VST l'ouvrir : desactive le FM-1
  dans Preferences > Link/Tempo/MIDI le temps du transfert, ou passe par la version autonome.
- "Exporter / Importer une sauvegarde (.bak)" : la meme chose en fichier ; la page Backup du site LOAF BREAKER
  les envoie aussi au FM-1 depuis Chrome.

JOUER LE VST AVEC LE FM-1 (MENU > Machine FM-1 > Jouer le VST avec le FM-1)
- Le FM-1 branche en USB devient le clavier du VST : ses touches blanches et noires, ses boutons, ses 7 encodeurs
  et son MASTER jouent le VST, et ses LEDs s'allument comme celles du VST (les touches appuyees s'allument aussi sur
  les pads du VST). Le FM-1 se tait pendant ce temps, son ecran dit CONTROLLER.
- Il faut LOAF BREAKER 0.9.79 ou plus sur le FM-1. En haut a droite, "FM-1 ..." = en attente, "FM-1 *" = connecte.
- Debranche le FM-1 ou decoche l'option : il redevient lui-meme en 3 secondes, ses reglages intacts.
- L'option est gardee : le VST reprend la main sur le FM-1 a chaque ouverture tant qu'elle est cochee.
- Dans Ableton (Windows) : le plus simple est de laisser le FM-1 desactive dans Preferences > Link/Tempo/MIDI
  (Entree et Sortie) : le VST ouvre lui-meme le FM-1. Si Ableton garde l'entree du FM-1, route-le vers la piste du
  VST (Entree MIDI : FM-1, canal 16, Monitor : In) : les touches passent par Ableton, les LEDs par le VST tant que
  la sortie du FM-1 reste libre.

L'INTERFACE
- En haut : les categories (LIVE, SOUNDS, PATTERN, SONG, MIX, EFFECTS, ARP, SYSTEM), puis leurs onglets.
- Dessous, le son en grand : sur SOUNDS > KICK, le kick tel que le moteur du FM-1 le joue (ATTACK : ses 60
  premieres ms, BODY : 400 ms, TAIL : le kick entier et sa fin ; 60 MS / 400 MS / 1.5 S / AUTO pour changer), a cote
  le kick (ses 20 memoires, ECOUTER, COPIER / COLLER, ses couches) ; sur DRUMS la snare, le hat ou le clap ; ailleurs
  le break, detaille, ses slices (un clic joue la slice).
- Puis toutes les parties de l'onglet, une carte chacune : les couches ont leur couleur partout (SUB rouge, PUNCH
  orange, GRIT vert, CLICK bleu, TOK violet), les choix qui se dessinent sont des vignettes (MODE, CURVE, D+ TYPE...),
  les niveaux des faders, les 4 potards du FM-1 des potards ronds. Sur FX1 / FX2 (et EFFECTS) : l'effet a choisir.
- PADS (en bas) : un clic deplie les pads en grand, REPLIER les replie.
- SHIFT (maintenu) : les reglages de SEL.
- MENU : le skin (LOAF LORD par defaut), le clavier (chaque touche reglable), l'ecran du FM-1 (a afficher ou non),
  Machine FM-1 (le jouer en controleur, la gestion, les sauvegardes).

DANS ABLETON
- LOAF BREAKER suit le tempo d'Ableton et demarre a la mesure suivante quand tu lances la lecture
  (case "Host sync" en haut ; decoche-la pour utiliser son propre PLAY).
- Les notes MIDI : 48 a 63 (C3 a D#4) jouent les slices, 36 le kick, 38 la snare, 39 le clap, 42 le hat.
- La sauvegarde du projet Ableton garde tout (kicks, patterns, splits, chaos...).
- Clavier de l'ordinateur : ESPACE = PLAY ; les lettres jouent les touches (affichees dessus).
